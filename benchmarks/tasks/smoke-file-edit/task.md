# Smoke: edição e validação simples

## Objetivo

Em um repositório de teste, faça uma alteração pequena e verificável em um arquivo existente.

## Limites

- Não altere arquivos fora do escopo definido pela tarefa real.
- Execute somente o comando de validação informado pelo repositório.

## Definição de pronto

- a alteração solicitada está correta;
- a validação passa;
- o agente relata os arquivos modificados e o resultado da validação.

## Adaptação

Este é um esqueleto. Antes de medir, substitua-o por uma solicitação concreta e fixe o commit inicial do repositório avaliado.
