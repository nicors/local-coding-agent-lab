# Modelos

Pesos e artefatos de modelo não são versionados. Para cada candidato, registre:

- origem e licença;
- nome e revisão exatos;
- formato e quantização GGUF;
- tamanho em disco;
- checksum;
- compatibilidade observada com tool calling;
- data e responsável pelo download.

Comece com dois ou três candidatos, não com uma coleção extensa.
